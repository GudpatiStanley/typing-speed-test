# Typing Speed Test

A browser-based typing speed test with three difficulty levels, live WPM and accuracy tracking, and a local leaderboard.

## Live Demo
https://gudpatistanley.github.io/typing-speed-test/

## Features
- Easy, Medium, and Hard difficulty levels with different passages and time limits
- Real-time Words Per Minute (WPM) and accuracy calculation
- Leaderboard saved locally in the browser, filterable by difficulty

## Built With
- HTML, CSS, JavaScript (vanilla, no frameworks)
- Browser localStorage for persistence
